Effect CMP — local end-to-end host

This page embeds cmp.js exactly like a client site would, but points the config fetch at the local config worker and the consent POST at the local consent worker.

What needs to be running

  • Banner build watcher: bun --filter @effect-cmp/banner run dev
  • Local static server (this page): bun --filter @effect-cmp/banner run serve:local → http://127.0.0.1:4173/test/e2e/fixtures/host-local.html
  • Config worker: bun --filter @effect-cmp/edge run dev:config → port 8787
  • Consent worker: bun --filter @effect-cmp/edge run dev:consent → port 8788
  • Laravel API (Herd or php artisan serve)

Replace the domain id

Set data-domain-id on the script tag below to a real domain's publicKey from your local admin. The config worker reads from local KV, which Laravel populates on banner-config publish.
